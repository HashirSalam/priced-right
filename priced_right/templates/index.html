How to read it

Expected asking price
What similar listings typically ask, estimated from {{ "{:,}".format(n_listings) }} Tori.fi listings.
The band
Where {{ range_pct }}% of similar listings' asking prices fall.
This listing buyer mode
The price you entered. Below or above means it's outside the band, in line means inside it. The percentage compares it with the expected asking price.

Asking prices, not sale prices, and not a phone's true value.

How this works

A gradient boosting model trained on {{ "{:,}".format(n_listings) }} iPhone listings collected from Tori.fi in {{ collected_at.strftime("%B %Y") }}. It uses the model's release year and tier, storage, condition, seller type and damage. The range is built from the model's past errors: on listings it had never seen, it held 77% of asking prices.

These are asking prices, not sale prices, and not a phone's true value.
